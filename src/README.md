# Customer Nexus System - Hyper Edition Final v46

顧客管理システム - Excelファイルから顧客データを読み込み、検索・ソート・関係図の可視化を行うGUIアプリケーション

## プロジェクト構造

```
.
├── customer_app.py          # メインアプリケーション（エントリーポイント）
├── customer_app_backup.py   # 元のファイルのバックアップ
├── utils/                   # ユーティリティモジュール
│   ├── __init__.py
│   ├── text_utils.py       # テキスト処理（正規化、カタカナ変換など）
│   ├── date_utils.py       # 日付処理（パース、フォーマット、曖昧検索）
│   └── browser_utils.py    # ブラウザ起動処理
└── graph/                   # グラフ生成モジュール
    ├── __init__.py
    └── graph_generator.py  # NetworkX/Pyvisを使った関係図生成
```

## 主な機能

### 1. データ読み込み
- Excelファイル（.xlsx）のドラッグ&ドロップ対応
- ファイル更新の自動検知と再読込機能
- バックグラウンドでの非同期読み込み

### 2. 検索機能
- **新規検索**: 全データから検索
- **絞り込み検索**: 現在の検索結果からさらに絞り込み
- **プリセット検索**: 登録名、誕生日、電話番号の専用ボタン
- **検索対象列の選択**: ヘッダークリックで検索対象列を選択可能

### 3. 生年月日の曖昧検索（強化版）

#### 対応パターン例
元データが `H01/02/03` (平成1年2月3日 = 1989年2月3日) の場合、以下の入力でヒット：

- **元号付き**: `H1-2-03`, `H01.02.3`, `H010203`
- **元号省略**: `0123`, `123`, `010203`, `10203`
- **西暦**: `1989.2.3`, `89.2.03`, `8923`, `89023`, `19890203`
- **月日のみ**: `0203`, `23`

#### 仕組み
1. データ読み込み時に各生年月日から全ての省略形候補を生成
2. 検索インデックス `__birth_search_index__` に格納
3. 検索時に数字のみを抽出して部分一致検索

### 4. ソート機能
- ヘッダー右クリックでソート（昇順→降順→解除）
- 自然順ソート（数値を数値として扱う）
- 生年月日は日付型でソート

### 5. 関係図生成
- データ行をダブルクリックで関係図を生成
- NetworkXで有向グラフを構築
- Pyvisでインタラクティブなビジュアライゼーション
- Chromeのシークレット+アプリモードで表示

## 使い方

1. `customer_app.py` を実行
2. Excelファイルをドラッグ&ドロップ、または「📂 EXCEL読込」ボタンでファイル選択
3. 検索ボックスにキーワードを入力して検索
4. データ行をダブルクリックで関係図を表示
